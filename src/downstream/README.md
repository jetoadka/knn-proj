# Downstream: Face Recognition Fine-tuning

This module handles training and evaluating a face recognition model on the
newspaper-style augmented datasets generated by the CUT style transfer.

## Pipeline Overview

```
CUT checkpoint ──► generate_augmented_data.py ──► augmented images
                                                      │
clean faces (WebFace4M) ──► prepare_timm_dataset.py ──┤──► train_downstream.py ──► model.pth
                                                      │         │
real newspaper faces ─────────────────────────────────┘         ▼
                                                       evaluate (metrics.py)
```

## Quick Start

### 1. Generate augmented data (using trained CUT)

```bash
python -m src.downstream.generate_augmented_data \
    --input-dir data/webface4m \
    --output-dir data/augmented_newspaper \
    --checkpoint-dir src/style_transfer/cut_model/checkpoints/exp_combined \
    --batch-size 16
```

### 2. Prepare training datasets

```bash
# E1: Baseline — clean only
python -m src.downstream.prepare_timm_dataset \
    --sources data/webface4m \
    --output-dir data/downstream/E1_baseline/train --mode train

# E2: Augmented — clean + CUT-generated
python -m src.downstream.prepare_timm_dataset \
    --sources data/webface4m data/augmented_newspaper \
    --output-dir data/downstream/E2_augmented/train --mode train

# E3: Mixed — clean + CUT-generated + real newspaper
python -m src.downstream.prepare_timm_dataset \
    --sources data/webface4m data/augmented_newspaper data/people_gator/aligned_112/train \
    --output-dir data/downstream/E3_mixed/train --mode train
```

### 3. Train models

```bash
# Each experiment
python -m src.downstream.train_downstream --config configs/baseline_clean.yaml
python -m src.downstream.train_downstream --config configs/augmented_newspaper.yaml
python -m src.downstream.train_downstream --config configs/augmented_mixed.yaml
```

### 4. Quick local test (Mac MPS)

```bash
python -m src.downstream.train_downstream \
    --train-dir sample_data/webface4m \
    --val-dir sample_data/wiki_face_112 \
    --backbone convnext_atto \
    --epochs 2 --batch-size 8 --device mps \
    --run-name smoke-test --wandb-mode offline
```

| File | Purpose |
